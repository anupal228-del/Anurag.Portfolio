# Anurag Pal — Creative Portfolio (Clean Version)

A responsive single-page portfolio rebuilt from the supplied 12-page portfolio PDF.

## What's improved
- Removed full-page PDF screenshots that repeated text already present in HTML.
- Kept a standalone portrait crop in the About section.
- Rebuilt the tools area as readable text categories instead of a screenshot.
- Consolidated the About copy into one introduction.
- Rebuilt brand experience as a clean text grid.
- Added responsive navigation and subtle scroll-reveal animations.
- Kept the black, warm-white and red editorial visual identity.

## Publish with GitHub Pages
1. Create a new public repository.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, then `main` and `/(root)`, and Save.
5. GitHub Pages looks for `index.html` at the top level of the publishing source.

## Edit
- `index.html`: portfolio content
- `style.css`: design and responsive layout
- `script.js`: menu and scroll animations
- `assets/anurag-portrait.jpg`: portrait image
